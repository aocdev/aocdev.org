JDocusaurus

Java annotation processor for generating Docusaurus microservice documentation
Overview
Java 21+ Apache 2.0 Annotation Processor (APT) Maven 3.8+ Docusaurus

JDocusaurus is a Java library for generating deep microservice documentation in Docusaurus format, using annotations and compile-time processing (APT). Annotate your code with @JDoc* and automatically get: Markdown pages with endpoints, Mermaid sequence diagrams, ER diagrams, event maps, business rules, external integrations, configuration tables, and a ready-to-publish Docusaurus structure — with zero runtime overhead.

Processing happens exclusively at compile time (RetentionPolicy.SOURCE). No reflection, no agents, no Spring or framework dependency required.

github.com/aocdev/JDocusaurus
Key Features
Zero runtime Annotation processing happens only at compile time (RetentionPolicy.SOURCE). No agents, no reflection, no framework dependency.
Mermaid diagrams Automatic generation of sequence diagrams, ER diagrams, event maps, and dependency graphs using Mermaid syntax.
Auto-flow detection JavaParser statically analyses source code to detect method call chains on injected fields and generates sequence diagrams automatically, recursively, with conditional branch detection.
Hybrid JPA support Enriches entity documentation with JPA metadata (@Entity, @Column, @Id, @OneToMany…) without requiring JPA as a compile dependency. @JDoc* annotations always take priority.
Full Docusaurus output Generates index.md, sidebars.js, and per-controller / per-entity / per-event Markdown files ready to drop into a Docusaurus project.
Business rules Documents business rules grouped by severity: MANDATORY, WARNING, INFO.
External integrations Documents external services (REST, gRPC, messaging…) and generates a Mermaid dependency map.
Configuration docs Documents configuration properties. Secrets (secret = true) are masked with *** in the output.
Configurable Output directory, project name, description, auto-flow depth and more via Maven compiler args (-Ajdoc.*).
Annotation Reference
REST API
Annotation Target Description
@JDocClass TYPE Documents an API controller / class. Accepts name, description, basePath, version.
@JDocEndpoint METHOD Documents an HTTP endpoint. Accepts method, path, description, summary, auth.
@JDocParam PARAMETER Documents an endpoint parameter. Accepts name, description, location (PATH / QUERY / HEADER / BODY), example.
@JDocResponse METHOD Documents an HTTP response. Accepts code, description. Repeatable.
@JDocHeader METHOD Documents an HTTP request header. Accepts name, description. Repeatable.
Flows & Sequence Diagrams
Annotation Target Description
@JDocFlow TYPE, METHOD Declares a named business flow with title and description.
@JDocFlowStep METHOD Defines a step within a flow. Accepts flow, order, from, to, message, returnMessage. Repeatable.
@JDocParticipant TYPE Declares a named participant for sequence diagrams.
Data Model
Annotation Target Description
@JDocEntity TYPE Documents a data entity. Accepts name, description, table.
@JDocField FIELD Documents an entity field. Accepts description, nullable, constraints, example.
@JDocRelation FIELD Documents a relationship between entities. Accepts target, type (ONE_TO_ONE / ONE_TO_MANY / MANY_TO_ONE / MANY_TO_MANY), description.
Events & Messaging
Annotation Target Description
@JDocEvent TYPE Declares a domain event. Accepts name, description, topic, schema.
@JDocProduces METHOD, TYPE Marks an event producer. Accepts event, topic, description. Repeatable.
@JDocConsumes METHOD, TYPE Marks an event consumer. Accepts event, description, group. Repeatable.
Business Rules, Integrations & Configuration
Annotation Target Description
@JDocBusinessRule METHOD, TYPE Documents a business rule. Accepts id, rule, severity (MANDATORY / WARNING / INFO), relatedRules. Repeatable.
@JDocExternalService TYPE, FIELD Documents an external service dependency. Accepts name, description, type (REST / GRPC / MESSAGING / DATABASE / …), url, owner.
@JDocConfig FIELD, TYPE Documents a configuration property. Accepts key, description, required, defaultValue, example, secret. Repeatable.
Installation

Add the dependencies to your pom.xml:

<dependencies>
    <dependency>
        <groupId>org.aocdev</groupId>
        <artifactId>jdocusaurus-annotations</artifactId>
        <version>1.0-SNAPSHOT</version>
        <scope>provided</scope>
    </dependency>
    <dependency>
        <groupId>org.aocdev</groupId>
        <artifactId>jdocusaurus-processor</artifactId>
        <version>1.0-SNAPSHOT</version>
        <scope>provided</scope>
    </dependency>
</dependencies>

Optionally configure processor options via maven-compiler-plugin: 

<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.13.0</version>
            <configuration>
                <compilerArgs>
                    <arg>-Ajdoc.projectName=User Service</arg>
                    <arg>-Ajdoc.projectDescription=User management microservice</arg>
                    <arg>-Ajdoc.fullStructure=true</arg>
                </compilerArgs>
            </configuration>
        </plugin>
    </plugins>
</build>

Then compile and documentation is generated automatically: 

./mvnw clean compile

Markdown files are generated in target/classes/docs/ by default.

Processor Options
Option (-Ajdoc.*) Description Default
jdoc.outputDir Output directory. Relative paths write via Filer to target/classes/docs/; absolute paths write directly with java.nio.file.Files. docs
jdoc.fullStructure Generates sidebars.js for Docusaurus alongside the Markdown files. false
jdoc.projectName Project name used as the main page title. (first controller name)
jdoc.projectDescription Project description shown on the main page. (empty)
jdoc.autoFlowDepth Maximum recursion depth for JavaParser automatic flow detection. 5
jdoc.autoFlowEnabled Enables or disables automatic flow detection via JavaParser. true
Generated Output Structure

With jdoc.fullStructure=true, the following directory tree is generated: 

docs/
  index.md                    # Main page with summary diagrams
  sidebars.js                 # Docusaurus sidebar configuration
  api/
    index.md                  # Controller and endpoint index
    user-controller.md        # Per-controller documentation
  flows/
    index.md                  # Flow index
    user-registration.md      # Per-flow sequence diagram
  data-model/
    index.md                  # Global ER diagram + entity table
    user-entity.md            # Per-entity fields and relationships
  events/
    index.md                  # Event map + summary table
    user-created-event.md     # Per-event producers/consumers
  business-rules/
    index.md                  # Rules grouped by severity
  integrations/
    index.md                  # Dependency map + service table
  config/
    index.md                  # Configuration properties table

To integrate with Docusaurus, install the Mermaid plugin (npm install @docusaurus/theme-mermaid) and enable it in docusaurus.config.js. See the README for full instructions.
