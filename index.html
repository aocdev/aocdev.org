Project Summary
JDocusaurus
Java 21+ Apache 2.0 Annotation Processor (APT) Maven

A Java library for generating deep microservice documentation in Docusaurus format, using annotations and compile-time processing (APT). Zero runtime overhead.

JRuntime-Inspector
Java 21+ Apache 2.0 Zero Dependencies Maven Central

A lightweight, framework-agnostic runtime profiling library for JVM applications. Instrument your code and get a hierarchical Markdown report pinpointing where execution time goes.
